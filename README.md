# 🌟 Captrio – Smart India Hackathon Project

## 📖 About the Project
Captrio is an accessibility-focused application developed as part of the Smart India Hackathon. It aims to make communication easier and information more accessible through speech, text, multilingual support, and assistive features.

## ✨ Features
- 🎙️ **Speech-to-Text:** Converts speech into text.
- 🎬 **Video Transcript Generation:** Generates transcripts from video content.
- 🌍 **Multilingual Communication:** Supports communication across multiple languages.
- 📚 **Contextual Glossary:** Provides word meanings and explanations.
- 🤟 **Sign Language Support:** Supports sign-based communication.
- 🆘 **SOS Assistance:** Provides emergency assistance through SOS features.
- 📝 **Text Simplification:** Makes complex text easier to understand.

## 🛠️ Technologies Used
- **Frontend:** Flutter
- **Backend:** Python, FastAPI
- **Languages:** Dart, Python

## 🚀 Getting Started
1. Clone the repository.
2. Install the required dependencies.
3. Configure the necessary environment variables.
4. Run the frontend and backend applications.
